# 产品需求文档（PRD）

> 状态：已冻结（2026-10-05 与产品负责人确认；同日确认「一餐组合」范围变更）

## 1. 产品契约

| 项 | 内容 |
|---|---|
| 产品名 | 稳稳吃 |
| 负责人 | LJP095 |
| 一句话 | 填一次个人情况，每天告诉你「这一顿吃什么」——一餐家常菜组合，符合三高饮食限制 |
| 要解决的问题 | ① 每天不知道吃什么；② 不确定吃的食物是否满足三高（血糖/血压/血脂）饮食要求 |
| 目标用户 | 三高人群（第一版自用，预留多人扩展） |
| 核心对象 | 一餐组合（由家常菜「菜品」组成，菜品带每份热量/碳水/钠/脂肪/胆固醇） |
| 支持对象 | 食材营养数据（中国食物成分表）、用户个人资料 |
| 主流程 | 打开 → 填写个人情况与三高限制 → 保存 → 自选菜数 → 获得一餐家常菜组合推荐 |
| 体验定位 | 极简工具（干净直接，打开即用） |
| 形态 | 网页（纯前端静态站） |

## 2. 第一版范围

### 必做（In）

1. 个人资料填写一次并保存（身高 / 体重 / 年龄 / 活动量 + 三高指标[可选] + 忌口）
2. 三高「浅做」：血糖、血压、血脂三项基础规则
3. 一餐组合推荐：用户自选菜数（几荤/几素/几主食/要不要汤），从家常菜库组装
4. 判定标准「两者结合」：个人指标优先 + 通用膳食指南默认值兜底
5. 判定口径：硬指标（碳水/钠/胆固醇）整餐合计，其余（总脂肪）逐菜
6. 推荐原因解释（为何符合 / 为何排除）
7. 覆盖中餐（内置家常菜库）
8. 极简工具体验

### 明确不做（Out）

- 摄入记录与「是否达标」分析
- 登录注册 / 多人
- 健身 / 过敏 / 文化类需求（仅预留字段）
- 复杂推荐引擎（先用规则过滤，不做算法）

### 预留（Reserve）

- 健身 / 过敏 / 文化需求字段
- 多人扩展
- 摄入记录
- 智能配餐（自动搭配；第一版为用户自选菜数）

## 3. 成功标准

1. **操作简单**：填一次资料即可长期用
2. **覆盖中餐**：推荐的饭菜是常见中餐家常菜
3. 推荐结果符合三高限制
